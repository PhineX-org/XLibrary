تثبيت XAMPP وإعداد المشروع
قبل ما نكتب أي كود PHP، محتاجين نثبّت XAMPP — وهو برنامج بيشغّل Apache و MySQL على جهازك محلياً. بكده هتقدر تشغّل PHP من غير ما تحتاج سيرفر.
📦 خطوات التثبيت
١
روح على apachefriends.org وحمّل XAMPP لنظامك (Windows/Mac/Linux)
٢
ثبّت البرنامج واختار تثبيت Apache + MySQL + PHP
٣
افتح XAMPP Control Panel وابدأ Apache و MySQL (اضغط Start)
٤
افتح مجلد C:\xampp\htdocs (على Windows) وانشئ مجلد جديد اسمه php-login
٥
جوا المجلد انشئ ملف اسمه test.php واكتب الكود اللي في التاب — كما هو
٦
افتح المتصفح وروح على localhost/php-login/test.php
٧
لو شفت صفحة PHP Info معناها كل حاجة شغّالة ✅
مجلد المشروع الكامل:
htdocs/php-login/

الملفات اللي هنبنيها:
📄 index.php — صفحة الـ login
📄 db.php — الاتصال بالـ DB
📄 register.php — التسجيل
📄 login.php — تسجيل الدخول
📄 dashboard.php — الـ dashboard
📄 logout.php — تسجيل الخروج
