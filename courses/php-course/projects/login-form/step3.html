تصميم CSS لصفحة الـ Login
هنضيف CSS احترافي لصفحة الـ Login والـ Register. الهدف تصميم dark theme جميل مع animations على التابين والـ inputs.
🎯 المهام
١
أضف background داكن لـ body — استخدم gradient أو لون #0f172a
٢
صمّم .auth-wrapper بـ border-radius و box-shadow وعرض max-width: 420px
٣
صمّم .tab-btn.active بلون مختلف يبرز الـ tab المحدد
٤
الـ .auth-form يكون display: none والـ .auth-form.active يكون display: flex
٥
أضف transition على الـ inputs عند :focus مع تغيير border-color
٦
اضغط تشغيل وتأكد إن الصفحة تبدو احترافية في الـ preview
