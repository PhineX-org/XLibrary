ملف db.php — الاتصال بـ MySQL
هنكتب ملف db.php اللي بيعمل اتصال بين PHP وقاعدة البيانات. هنستخدم PDO — أكتر أمان من mysqli.
✏️ المهام
١
حدد ثوابت الاتصال: DB_HOST, DB_NAME, DB_USER, DB_PASS
٢
أنشئ PDO object باستخدام new PDO($dsn, $user, $pass)
٣
فعّل PDO::ATTR_ERRMODE = PDO::ERRMODE_EXCEPTION
٤
فعّل PDO::ATTR_DEFAULT_FETCH_MODE = PDO::FETCH_ASSOC
٥
لفّ الاتصال في try { } catch (PDOException $e) { }
٦
في الـ catch أظهر رسالة خطأ مناسبة (وأوقف التنفيذ)
إعدادات XAMPP الافتراضية:
Host: localhost
User: root
Password: (فارغ)
Database: php_login_db
💡 ليه PDO؟ PDO بيدعم Prepared Statements اللي بتحمي من SQL Injection أوتوماتيك — أهم ثغرة في مواقع الويب.
