إنشاء قاعدة البيانات MySQL
هنستخدم phpMyAdmin (جوا XAMPP) عشان نعمل database وجدول users يخزّن بيانات المستخدمين.
📋 خطوات phpMyAdmin
١
افتح المتصفح وروح على localhost/phpmyadmin
٢
اضغط New في الشريط الجانبي لإنشاء database جديدة
٣
سمّيها php_login_db واختر utf8mb4_unicode_ci
٤
اضغط SQL في القائمة العليا والصق الكود من التاب schema.sql
٥
اضغط Go لتنفيذ الأوامر — هيتعمل جدول users أوتوماتيك
٦
اكتب اسم الـ database في تاب db_name.txt للتحقق
أعمدة جدول users:
id — INT AUTO_INCREMENT PRIMARY KEY
username — VARCHAR(50) UNIQUE
email — VARCHAR(100) UNIQUE
password — VARCHAR(255) (مشفّر)
created_at — TIMESTAMP
🔐 أمان مهم الـ password يتخزّن مشفّراً باستخدام password_hash() في PHP — مش plain text أبداً!
