هيكل HTML — صفحة Login و Register
هنبني صفحة واحدة index.php بها تابين: تاب للـ Login وتاب للـ Register. المستخدم يضغط على التاب اللي يريده والفورم بيتبدل.
📝 المهام
١
تأكد من وجود div.auth-wrapper كـ container رئيسي للصفحة
٢
تأكد من وجود div.tab-btns يحتوي زرارين: btn-login و btn-register
٣
تأكد من وجود form#login-form بـ inputs: email و password
٤
تأكد من وجود form#register-form بـ inputs: username و email و password
٥
كل فورم له action يشير لملف PHP الخاص به (login.php أو register.php)
٦
اضغط تشغيل وتأكد إن التابين بيظهروا في الـ preview
طريقة عمل التابين:
— JavaScript بيشيل active من الفورم الحالي
— ويضيفها على الفورم التاني
— CSS بيخبي الفورم اللي مالوش class="active"
