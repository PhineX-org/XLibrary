register.php — حفظ المستخدم في الـ DB
هنكتب ملف register.php اللي بيستقبل البيانات من فورم التسجيل، يتحقق منها، ويحفظها في قاعدة البيانات.
✏️ المهام
١
تأكد أن الـ request هو POST قبل أي معالجة
٢
اسحب البيانات من $_POST ونظّفها بـ trim() و htmlspecialchars()
٣
تحقق: password وـ confirm_password متطابقان، وطول password >= 8
٤
تحقق: البريد الإلكتروني غير مستخدم من قبل (query للـ DB)
٥
شفّر الـ password بـ password_hash($password, PASSWORD_BCRYPT)
٦
أدخل البيانات بـ Prepared Statement واحفظها في جدول users
٧
حوّل المستخدم لصفحة Login بـ header('Location: index.php')
خطوات المعالجة:
1. استلام البيانات من $_POST
2. Validation (التحقق من الصحة)
3. هاش الـ password
4. INSERT في DB بـ PDO prepare
5. Redirect للـ Login
🔐 أمان إلزامي لا تخزّن password بدون تشفير أبداً.
استخدم password_hash() دائماً.
