Getting Started | البدء

.اتبع الخطوات التالية لإعداد بيئة التطوير والكتابة الأولى للكود

1 تحميل VS Code

Visual Studio Code هو معدل كود شائع لتطوير الويب.

  • روح ل code.visualstudio.com.
  • حمل النسخة الي تناسب نظام التشغيل بتاعك (Windows/Mac).
  • شغل النسخة واتبع معالج الإعداد.

2 اعمل مجلد للمشروع

التنظيم مهم جداً! حافظ على ملفات الكود في مكان واحد.

  1. اعمل مجلد باسم أول-مشروع
  2. افتح VS Code.
  3. روح ل File > Open Folder... أختار ملفك "أول-مشروع"

3 اعمل ملف HTML الأول

عند الناحية الشمال (الجزء الشمال من VS Code):

  • اضغط على New File
  • سميه index.html. ملاحظة: استخدم دائماً نوع الملف .html!

4 ميزه سحرية

بدل ما تقعد تكتب المحتوى الاساسي يدويًا اتبع التعليمات

  1. جوه الملف index.html, أكتب !.
  2. و اضغط على Enter or Tab.
  3. VS Code !هيكتب الاساسبات بسرعة
