أساسيات الـ HTML - الدرس الأول 🚀

1. إيه هي الـ Metadata؟ (معلومات الصفحة)

دي معلومات مابتظهرش للي بيزور الموقع، بس مهمة جداً للمتصفحات ومحركات البحث (SEO). زي:

  • <head>: ده الصندوق اللي شايل كل الميتا داتا.
  • <title>: العنوان اللي بيظهر فوق في الـ Tab.
  • <link>: بنستخدمه غالباً عشان نربط ملف الـ CSS.
  • <meta>: بتعرف المتصفح اللغة، والوصف، والكلمات المفتاحية.

2. تقسيم الصفحة (Sectioning)

عشان الكود بتاعك يبقى "Semantic" (دلالي) ومفهوم، بنقسم الصفحة لأجزاء:

  • <header>: راس الصفحة (اللوجو والقايمة).
  • <nav>: خاص باللينكات التنقلية.
  • <main>: المحتوى الأساسي بتاع الصفحة.
  • <section> & <article>: لتقسيم المواضيع والمقالات.
  • <footer>: ديل الصفحة (حقوق النشر والروابط).

3. النصوص والروابط (Text Content)

دي الأدوات اللي بنفرش بيها الصفحة:

  • العناوين: من <h1> (الأكبر) لحد <h6> (الأصغر).
  • الفقرات: بنستخدم <p>.
  • الروابط: تاجات الـ <a> ولازم معاها صفة href عشان نحدد هتروح فين.
  • التعليقات (Comments): بتكتبها عشانك أنت، المتصفح مش بيعرضها. شكلها كده: <!-- كودك هنا -->.

💡 حركة صايعة: في VS Code لو علمت على أي كود ودوست Ctrl + / هيحوله لتعليق فوراً!
